# Responsive Login Screen (Traditional CSS)

Project developed during a practical class with the objective of studying classic CSS positioning techniques.

> **Important**
>
> This exercise **does not use Flexbox or CSS Grid**.
>
> The purpose of this lesson is to understand how responsive layouts were traditionally built using classic CSS techniques, providing a solid foundation before learning Flexbox in upcoming lessons.

---

## Project Objectives

During this exercise, several important CSS concepts were applied, including:

- Semantic HTML5 structure
- Position (`relative` and `absolute`)
- Centering using `transform`
- Float
- Media Queries
- Responsive Layout
- Backgrounds
- Box Shadow
- Border Radius
- HTML Forms
- Pseudo-classes
- CSS Transitions
- `calc()` Function

---

## Responsiveness

The project includes three responsive layout adaptations:

📱 Smartphones

- Column layout
- Image displayed at the top
- Form below

📲 Tablets

- Image positioned on the left
- Form on the right

🖥 Desktop

- Image positioned on the right
- Form on the left

Everything was built using only **Media Queries**, **Float**, and **Position**.

## Educational Purpose

This project was developed exclusively for learning purposes.

The goal of this lesson was to demonstrate how responsive interfaces were built using traditional CSS techniques, without relying on Flexbox or CSS Grid.

After mastering these concepts, the next step is learning modern layouts with Flexbox, followed by CSS Grid.
